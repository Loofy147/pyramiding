Pyramid Risk Lab v1.1.0 — verification record
Date: 2026-10-17
Target runtime: Node.js 22

Coverage added on top of the v1.0 baseline:
- Config normalization bounds for slippage, funding interval, and tail shock fields.
- Exact slippage ledger check on constant price paths.
- Funding accrual check: notional × rate × (hours / 8) × step count.
- Seeded tail-shock determinism and forced common negative shocks.
- Leverage scan comparison against direct simulations using the same path sample.
- UI assertions for all prototype-derived controls and the leverage-scan action.

Build consistency:
- standalone.html is generated from index.html plus the engine.js inline bundle.
- GitHub Actions runs npm test, rebuilds standalone.html, and rejects uncommitted build drift.

Known limitations:
- Pixel-level real-browser screenshot verification is not yet available.
- Maintenance tiers, partial liquidation, liquidation penalties, changed fill prices and live market conditions are not modeled.
- The three-asset prototype model was deferred rather than copying its isolated per-token liquidation logic.
